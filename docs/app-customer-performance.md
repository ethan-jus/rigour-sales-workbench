# 首页与客户页性能约定（2026-11-12）

详细证据：[DEV 真机验证记录](../../../outputs/app-customer-performance-20261112/验证记录.md)。仅 DEV，未发布生产、未删除临时打卡数据。

Android 12 测试机的默认粗体字体变体创建占用大量主线程时间。现有粗体样式在 `APP-ANDROID` 内指定 `font-family: sans-serif` 后：首页 onReady 926ms、排版 120ms；客户总览 onReady 310ms、排版 49ms。以后新增粗体时沿用该写法，勿仅凭 Web 预览恢复默认字体。此结论来自本机 A/B 和采样，不代表所有 Android 设备，也不代表整个 APP 启动耗时。

客户列表使用原生 `list-view` 和直接子级 `list-item`，保留完整查询条件、原生分页与固定筛选栏。不要改回一次性铺满整页的普通滚动容器。

`services/customer-cache.uts` 只保留最多 12 份、2 分钟的内存展示快照，隔离环境／租户／用户／会话／权限／完整查询条件。每次进入仍重新请求；进行中合并，失败清除，写入成功／账号变化失效。页面使用 generation 忽略过时响应，隐藏时失效；不能使用旧快照中的版本直接认领。无需向普通本地存储写入客户或联系人资料。

CRM 总览使用 COUNT 与当前授权范围，版本化服务端缓存最多 10 秒；客户端缓存不替代鉴权。正常登录、身份、签到、拜访和材料操作不使用展示快照判断是否允许执行。

验证命令：`pnpm app:v1:test`（本次 245 项）、`pnpm app:g0:check:android`、`pnpm app:g0:check:ios`、`pnpm app:g0:check:harmony`。后两端只编译；Android 已验证底部导航、日期、公私海切换、滚动分页。当前账号私海为空，有数据私海的真机滚动未验收。
