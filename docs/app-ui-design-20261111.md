# 销售工作台页面清单与首轮设计

2026-11-11。当前源码是 uni-app x、UTS、UVue，HBuilderX 5.26、VDOM。五个主导航下注册 12 个页面文件；复用页面内部还有多个业务视图。本轮只实施登录和首页设计。

## 功能与页面地图

| 页面 | 当前功能 | 后续设计顺序 |
| --- | --- | --- |
| home | 今日作业、草稿续接、本人拜访统计与常用入口 | 本轮 |
| login | 公司账号密码登录、会话恢复、错误反馈 | 本轮 |
| customers | 供应链客户查询、分页、详情入口、购物草稿，CRM 入口 | 下一轮 |
| crm | 本人客户、公海认领、门店详情、联系人、电话核验、关联联系人、经营状态、上班签到、拜访历史 | 随客户流程 |
| crm-visit | 接待人、沟通结果、意向、现场照片与录音、材料上传、离店与核验状态 | 随现场拜访 |
| visits | 本人正式拜访、本机草稿、日期查询、拜访计划入口 | 随拜访流程 |
| visit | 选择门店、现场记录、现场照片、本机材料、远端记录详情、今日计划，共 6 个视图 | 随拜访流程 |
| orders | 订单搜索、状态筛选、分页、详情入口 | 随交易流程 |
| commerce | 客户详情、商品列表/详情、购物草稿、收货信息、订单详情、回款/退货说明、草稿保存结果，共 9 个视图 | 随交易流程 |
| profile | 个人身份、业务入口、计划、草稿、消息与设置 | 最后统一 |
| work | 账号设置、目标业绩、消息待办、提成、到账，共 5 个视图 | 随个人工作 |
| device-check | 系统定位、原生录音、保存回放、生命周期检查 | 工具页收口 |

主要路径：启动自动恢复会话 → 首页（无有效会话时先登录） → 客户公海/本人客户 → 门店详情与联系人 → 上班签到/现场拜访 → 材料与结果 → 离店核验；交易路径为客户 → 商品 → 购物草稿 → 收货信息，以及订单列表 → 订单详情。

## 代码中的业务边界

CRM 正式拜访与旧 Sales 本机草稿流程并存。购物草稿、已提交订单、凭证提报和确认到账不能混称。当前 commerce 页面明确提示正式报价/订单提交、手机回款登记和退货申请尚未开放；业绩金额、提成、到账和公司消息也仍有待开通提示。这里是源码行为盘点，不代表服务端或真机验收结论。

## 首轮改动

- 登录：按用户反馈进一步精简，只保留 Logo 与工作台名称、横向账号/密码输入、显示密码与“登录”按钮。移除标题、介绍、环境标签、帮助、底部说明和重复返回入口；错误按需显示。
- 首页：作业入口优先；有 CRM 权限时进入客户拜访流程，有旧录音待处理时优先续接；购物草稿改为准确命名。
- 未接通的金额统计移出首页，业绩和到账仍有明确入口。本人拜访统计继续读取原有接口。
- 两页共享新的语义颜色与基础样式；其余页面和底部导航保留现有实现，随后逐页统一。

设计基线与线框见 [设计基线](../design-system/rigour-sales-workbench/MASTER.md)，细节见 [登录页](../design-system/rigour-sales-workbench/pages/login.md) 和 [首页](../design-system/rigour-sales-workbench/pages/home.md)。

## 首页按日常业务重新设计并实现

本轮先核对当前 CRM 上班签到和拜访前置、本人汇总 DTO、计划读取、商品读取及本机草稿状态，再写首页布局设计并渲染检查，最后改原项目 `app/pages/home/home.uvue`。没有新增页面、worktree 或另一份工程。

- 布局：原生“工作台”标题；日期与签到；今日拜访/有效拜访；一个橙色“开始拜访”主操作；拜访计划、查商品两个次级操作；有内容才出现的待处理草稿。
- 移除：首页欢迎词、操作解释、空草稿说明、月度统计解释、重复客户/我的入口，以及尚未接通的消息、业绩金额和到账快捷入口。底部五个主导航和相关业务页面保留。
- 签到复用既有 `crmWorkDayStatus` 与 `crmCheckIn`。进入首页只读状态，用户点击后才执行定位与签到；不自动签到。加载/重复点击受保护；失败原因保留并可重试。
- 汇总改为北京时间当天 `from=to=today` 的 `totalVisitCount` / `effectiveVisitCount`。缺失或失败保持“—”，不伪装为 0；同一服务错误只显示一次。
- 按权限收口请求与操作；账号/权限变化、重复刷新均丢弃旧响应。旧本机录音继续优先返回原记录；单份购物草稿直接继续，多份进入列表，不强行打开第一份。此轮没有重构 CRM 录音或新增其跨页恢复机制。
- 配色、字号、留白、按钮沿用已确认的登录页；两个次级入口新增同一笔画规格的线性 SVG。预览中补齐了原生/网页共用的显式边框样式。

设计见 `design-system/rigour-sales-workbench/pages/home.md`。设计稿 `outputs/app-ui-20261111/home-design.html` 与 `home-design-375.jpg`；实际页面截图 `home-implemented-sample-375.jpg`。截图均标注示例，不是账号经营数据；正式页面没有这些示例数据或预览控制器。
