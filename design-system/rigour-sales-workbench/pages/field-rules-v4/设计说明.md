# 签到与轨迹 V4 · 规则与交互设计

2026-11-18。设计评审稿，未接入接口、未发布规则。保留现有业务和拍照修复。

## 已确定的业务方向

用户确认：允许恢复作业，必须填写原因。普通签到不能重新打开已结束作业。

- 每名销售每个作业日一条主记录，可包含多个真实作业时段。
- 只配置作业日起点，建议 06:00；一天为 [当天06:00，次日06:00)，界面显示至次日05:59。签到、签退不再各设时间窗。时区使用北京时间，原始事件时刻不改变。
- 未开始：签到；作业中：签退；已签退：恢复作业（次级入口）。恢复必须填写原因，开启新时段和采集会话。不能覆盖早先签退，也不允许在已结束状态直接开始拜访。
- 作业时长为各签到/恢复至签退的有效时段相加，中间暂停不计时、不采集；里程也不跨休息时段连线。
- 进行中拜访应先结束或取消，才能签退。无须再添加常驻提示或定位同意弹窗。
- 重复点击/重试依幂等键只生成一个事件；后端执行状态限制，不能仅隐藏App按钮。

## 待实施的边界方案

- 到次日06:00仍未签退：结束上一作业日的采集资格，标记“缺签退”，不能伪造人工签退地址、将全天计为已核实工作时长或延续至新日。已发生的拜访/媒体保留，未结束拜访标记异常待处理，不生成有效完成。下一作业日经新签到开启；后端定时截止和App恢复前检查一致执行。
- 离线：已签到时段内位置本地保留后补传；签到、签退、恢复须服务端确认后才改变业务状态，失败在当前页面提供重试。记录实际事件时间与接收时间，不伪装成功。
- 跨截止点的离线补传仍绑定原作业日和会话，按配置期限接收，不能串入新日。时间/地点补正走留痕复核，不改原始事件。
- 新规则按“下一个作业日”生效；当前作业日含恢复时段继续使用已有版本。修改分界点时以旧周期结束边界为衔接点，避免产生重叠周期或漏掉时间；需在后端设计迁移生效边界，不能只改前端时间。

## 配置项

| 组 | 可编辑项 | 说明 |
|---|---|---|
| 适用范围 | 全部销售/指定团队，团队选择 | 复用现有组织目录和权限，不允许输入裸ID；正式实现保留现有其他范围，不能发布时丢失 |
| 作业日 | 每日开始时间 | 自动生成结束时间，删除独立签到/签退时段输入和旧运行分支 |
| 签退后 | 允许恢复作业 | 本次确认开启；开启则必填原因，原因要求是业务不变量，不再提供“免填原因”开关 |
| 工作时长 | 启用时长核验、标准/最低时长 | 标准值不用于强行阻止签退；低于最低值标记待复核。建议销售外勤默认不以时长作为有效拜访条件 |
| 位置记录 | 启用连续轨迹、采样间隔 | 开关关闭只影响连续轨迹，不取消签到/签退/拜访的单次定位证据 |
| 定位质量 | 可接受定位误差 | 用于轨迹质量筛选，不代表真实绝对精度；不把噪声当里程 |
| 断网补传 | 接受补传期限 | 保留原事件时间，按原会话处理 |
| 打卡补正 | 开关、申请期限 | 管理员复核留痕；不是反复改写下班卡 |

不再提供“是否必须签退”的含混开关：此业务里签退就是正常结束作业，缺失应标记异常。本设计不把每一条状态约束做成自由组合的开关。

## 轨迹页

- 一张低干扰底图，只保留必要道路与地标；正式地图用现有高德能力核验可用样式和POI密度，不承诺原生SDK不支持的样式效果。
- 数字1/2/3直接作为拜访标记，不加“拜访1”字样；同址多次访问尽量紧凑并列，点选显示具体时段，禁止为分开图标虚构经纬度。
- 只连接有效实际采样，单色路线和少量方向箭头。不画门店间估算直线，不同时叠加拜访顺序线。
- 首次签到/最后签退使用出发旗/黑白终点旗；中间恢复/签退在时间列表展开，按会话断线；地址完整保留在事件详情，不在地图贴一大片文字。
- 概览：有效记录里程、拜访数、累计停留。记录不足时不以0公里或漂移量冒充结果；显示“路线记录不足”，保留门店编号与真实时间。
- 点击编号联动下方门店条目；全屏只放地图和当前选中门店的一条摘要；不再加入两套轨迹页签与左右逐项按钮。
- 原型道路和12.6公里等为明确标注的演示数据，不用于验收。11月18日室内72米结果不可据此判断真实行走距离。

## 地图旗标重新设计（待审阅）

此前门框进出箭头方案被用户否定，已从当前原型和 SVG 素材中替换。

参考：
- https://labs.mapbox.com/maki-icons/ ：观察地图图标在小尺寸下的实心轮廓与辨识度。
- https://dribbble.com/shots/22109353-Location-Tracker-App ：观察低干扰底图、单色路线与端点层级。

本次独立绘制旗标，未拷贝参考作品图标。签到为蓝色三角出发旗，签退为黑白棋盘终点旗；拜访仍为橙色数字圆标。旗杆末端锚定实际打卡坐标，白色描边隔开道路背景。使用 PingFang SC，正文左对齐。基础色：白 #FFFFFF、地图灰 #E5E9EC、正文 #273442、签到蓝 #246BEB、路线橙 #E96326。

审核取舍：不再使用登录/退出语义；删除白底徽章和内层色块。三类标记依靠形状及纹样区分，不只依靠颜色。放大图只供查看细节，地图中按实际约 30 像素检视。

这里只更新设计原型，不发布规则，不修改真实轨迹数据或 App 业务实现。

## 工作时长展示

轨迹页地图下方增加工作时长，并显示首次签到、末次签退时间。示例09:08至18:32，工作9小时24分。单时段按签到至签退计算；恢复作业时按各已完成时段求和，当前时段计算至当前时间，签退后的间隔不计入。多时段需标注“分段累计”，首末时间不能作为净时长计算依据。工作时长独立于GPS采样，定位不足时仍显示；全屏地图隐藏摘要以保留地图空间。当前仅更新设计稿。
