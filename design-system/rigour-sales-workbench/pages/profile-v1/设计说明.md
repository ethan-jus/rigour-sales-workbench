# 我的 · 全流程设计 V1

2026-11-17。状态：**设计评审稿，未实施到 APP**。用户要求重新分析“我的”页，删除不适合的内容，完整设计相关子页面，方向为专业、精致、简洁、紧凑。此次只新增本目录文件，现有业务代码、拍照修复及其他未提交改动均保留。

## 一、定位与首页

“我的”承担个人身份、个人工作记录与应用自助服务。客户经营、拜访安排、订单作业和经营看板有各自业务入口，不再次聚集到个人中心。

首页采用：顶部“我的”及设置按钮 → 姓名/公司资料入口 → 两组四行服务 → 原有五项 Tab。个人工作包含外勤记录和声音登记；支持与服务包含材料同步和使用帮助。资料从头像区域进入，账号设置在右上角。同步正常仅显示行内状态；异常时出现可处理提醒。

没有大背景头像卡、统计数字墙、九宫格和彩色图标块。页面内容少时允许自然留白，不为填满页面添加功能。示例姓名、工号、外勤轨迹、录音时长等均为原型演示，不是业务结果。

## 三、页面树与完整流程

- 我的：正常、待同步提醒。
- 个人资料：正常、身份暂未确认、读取失败。
- 外勤记录：当日记录、日期选择、轨迹全屏、空态；核查事项 → 补充说明 → 原因选择 → 已提交说明。
- 声音登记：已登记、未登记、同意、录制、确认、失败、删除确认。
- 材料同步：已同步、待同步、同步中；问题进入对应帮助文章。
- 设置：个人资料、应用权限、关于、退出确认；录音中退出阻断、退出失败。
- 应用权限：定位/麦克风/相机用途与恢复路径，系统设置跳转示意。
- 使用帮助：有效拜访条件、同步问题、声音登记、资料问题四篇短文。
- 通用无权限：直接访问时解释原因，正常首页按权限隐藏不适用入口。

原型目录共 **37 个页面和状态视图**。日常入口数与设计视图数不同：异常与弹层不是首页新增菜单。

外勤记录中的正式拜访详情仍由已确认的 V3 拜访方案承接，本轮不重复设计或改动该业务。原型在此处提示去向；日期选择、系统设置、退出后的登录页为系统/既有流程边界，不在原型中伪造真实操作。

## 四、视觉规格

沿用销售工作台品牌：白底 #FFFFFF、石墨 #252A31、辅助文字 #626970、重点橙 #C64C1C、中性背景 #F5F6F7。绿色仅表示确认状态，橙色用于可行动事项；颜色同时配文字，不单独承担含义。

- 手机内容左右 20px；普通菜单约 58px 高；图标 22px、统一线宽。
- 页面导航标题 17px，正文 15–16px，说明 13px；身份姓名 27px。内容用字重和少量分隔线区分，不加一层层卡片。
- 主按钮至少48px，图标按钮48px；紧凑体现在去重和信息组织，不缩小重要触控区域。
- 底部按钮与滚动内容分离；长文、核查历史和朗读内容可滚动。
- 每个任务页只有一个主要动作；退出/删除有确认，失败保留可恢复状态。
- 使用设备中文系统字体，无网络字体依赖；无装饰动画。当前设计延续浅色应用，没有新增深色主题。

UI UX Pro Max 检索命中 Minimalism & Swiss Style 的企业工具适用性、信息层级及高密度建议；检索返回的营销转化布局、金蓝色和西文字体不适用于本产品，未采用。以现有 MASTER 为品牌基线，对本范围收紧菜单行高与间距。

## 五、真实能力与实现边界

| 内容 | 当前依据 | 实施要求 |
|---|---|---|
| 姓名、账号、公司 | session.uts 已有字段 | 不展示原始权限码/租户 UUID |
| 员工姓名、工号 | sales-profile.uts 已有读取 | 失败允许重新查询，不设计员工自改人事资料 |
| 外勤与核查 | fieldwork.uvue、fieldwork-statement.uvue、fieldwork-review.uts | 保留本人权限、缺失轨迹、原核查提交合同；说明已提交不等于核查通过 |
| 声音登记 | voice-profile.uts 已有 registered/name/revision | 同意默认不选；15秒最低/30秒最长沿用现状；失败保留样本，删除与重登记走原 revision 校验 |
| 材料同步 | crmUploadState 聚合状态及原上传队列 | 没有可靠百分比就不显示百分比；本稿没有虚构逐文件任务列表 |
| 版本 | manifest.json 现为0.2.1 | 实施用实际安装版本，不多处硬编码 |
| 权限用途/帮助 | 新增静态产品内容 | 状态未知不能写“已授权”；系统设置跳转须按 Android/iOS/Harmony 能力核验 |
| 退出登录 | auth.uts 现有凭据清除与失败重试 | 录音中先阻断；凭据清除失败不得假装退出成功 |

帮助中的10分钟仅说明当前默认拜访规则。最终实施应从本次拜访/适用规则取得门槛，不能另写独立有效性判断，更不能将声音登记当作有效拜访条件。

未设计没有来源的部门/岗位/手机号、收入数字、客服会话、在线升级、安全设备管理、密码修改或清除草稿功能。
