# 设计原型验证

2026-11-16。本记录只验证本目录 Web 设计原型，不代表原生 App、后台、数据库或真实定位已经实现。

## 已完成

- HTML 内脚本经 `node --check` 检查，字典 JSON 解析通过。
- 375×812、812×375 浏览器布局检查；两种尺寸 document scrollWidth 等于 clientWidth，无横向溢出。固定底部按钮保留内容底部滚动空间。
- 未接触：隐藏接待人与合作进展，出现原因选择；选择“未到营业时间”后，没有把营业中自动改成停业。
- 业务进展：高德由高意向切换到已合作，零售的独立状态保留。
- 示例照片与模拟完成：出现信息确认，完成后按钮禁用，页面显示“设计演示已完成”，不产生业务写入。
- 独立离店距离：到店 500、离店 400 时阻止预览；改成 800 时通过。全部是原型示例。
- 用户追加的必填校验：空营业状态、经营类型、接待人、高德进展、门头照、跟进时间共 6 项逐项提示；焦点落在营业状态。选择“待核实”后剩余 5 项，营业状态错误消失。切为未接触后，接待人及合作错误消失，改为未接触原因，剩余 4 项。

## 验证边界

- 手机壳是浏览器原型，不是 Redmi 新版本截图；原型中的录音、照片、草稿、联系人都是演示。
- 尚未做系统最大字号、原生键盘、安全区、屏幕阅读器和 Android/iOS/Harmony 真机验证。当前沿用 App 浅色设计，没有宣称深色适配。
- 原型没有真实字典权限、网络失败、停用字典、CRM 并发回写、自动离店和上传重试验证。实施验收清单见 [方案说明](方案说明.md)。
- 当前实际 App / Sales / CRM / Foundation 与管理后台代码均未因本设计任务修改，未维护数据库字典或发布规则。

## 本地预览

在销售工作台仓库运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory design-system/rigour-sales-workbench/pages/visit-fieldwork-v2
```

浏览器打开 `http://127.0.0.1:8766/`。已有本任务预览进程时直接访问，不重复启动。顶部可查看规则设计，底部可演示必填校验和自动离店；这些画布按钮不进入销售 App。
