# 首页 Frontend Design 对比稿 V4

2026-11-11。本轮使用用户明确指定的 frontend-design。交付一张新的视觉对比效果图，保持已选“图一整体 + 图二待办”的信息顺序和功能，不改 App 代码。

## 第一遍：视觉计划

产品是供体育用品供应链业务员每天使用的移动销售工作台。视觉服务于核对业绩、关注回款和进入工作，不能做成营销页面，也不能因追求极简再次删掉财务信息。

| Token | 色值 | 作用 |
|---|---|---|
| 页面白 | #FFFFFF | 页面、今日、待办列表 |
| 石墨 | #252A31 | 正文、交易金额 |
| 次级灰 | #626970 | 指标标签、日期、单据状态 |
| 品牌橙 | #C64C1C | 开始拜访、待回款重点、当前 Tab |
| 总览灰 | #F5F6F7 | 唯一的月度数据分组底色 |
| 浅橙 | #FFF2EA | 待回款数量的小面积状态底色 |

系统中文 PingFang SC / HarmonyOS Sans / 本地系统回退，一套字体；数字采用等宽数字特性，不使用代码等宽字体。页面标题22、主要金额30–32、今日数字24、区块标题17、待办行16、普通标签14、辅助日期12。减少重黑字，常规正文400、主要数值600。Logo继续复用原有品牌。

布局：月度信息作为唯一轻灰整体，今日数字留在白面上，快捷操作紧凑一行，待办沿用三行入口加一条客户预览。左右24px，模块24px，内部8/12/16px；同类数值、行尾数量、箭头使用固定对齐线。

## 第二遍：对照需求审查

不采用每个指标独立卡片的默认仪表盘做法；只把同一时间/业务总览的数据放入一个低对比表面。此前的今日浅灰卡取消底色，使主次与“先月度、再今日”的业务顺序一致。圆角仅用于分组和按钮，不给所有列表行套卡片。

不增加装饰曲线、伪增长率、插画、欢迎语或说明。主要金额保留两列；64笔和12笔各自绑定对应金额。图二的待办三行、一个回款预览保留，依靠字号、字重、行距和图标一致性产生差异。

主要视觉重点只放在月度业务总览；橙色集中在回款金额与开始拜访，非重点待办计数用石墨。主要行动仍是开始拜访，其余入口使用小而清晰的统一线性图标。

## 生成与交付

使用内置 Image Gen，参考已选融合稿V3、原Product Design图一和已认可登录截图。生成一张390×844逻辑视口的手机内容效果图，不含设备框、系统状态栏或设计说明。日期2026-11-11周三；业务数值沿用V3虚构示例。

这是视觉稿；字体渲染、具体间距、触控区域、动态字号与原生兼容性在实现时检验。本轮不声称位图已通过交互或真机验收。

输出：`outputs/app-ui-20261111/home-frontend-design-v4-proposal.png`。使用内置 Image Gen 生成，图像为预览提案，没有替换任何运行页面。

## 生成后目视复核

- 月度数据进入同一个轻灰区域；今日数据回到白面，标签在数字上方，形成可见的分组差别。
- 交易额128,600、待回款42,780、本月回款93,400；订单数64与12各自归属清楚。今日6笔、8,600交易、6,200回款与上一版保持一致。
- 待办三行、一个客户预览、四个快捷操作和五个底部Tab均保留，未出现截断。
- 图像中的字号、圆角和图标只是视觉目标，不能据此声称精确像素和触控已验收。开发时使用实际品牌资源、统一矢量图标和纯色按钮。
- 取舍：V4月度信息分组更明确；V3上半屏更通透。没有替用户最终确认V4，也没有重写已实现首页。
