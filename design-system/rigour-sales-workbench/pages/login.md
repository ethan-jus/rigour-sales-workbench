# 公司账号登录

2026-11-11 按用户反馈精简。覆盖 MASTER.md 中首版登录页的信息结构。

静态界面只保留品牌 Logo、瑞盖销售工作台、账号、密码、眼睛图标、保持登录与“登录”按钮。取消宣传标题、用途说明、开发环境标签、密码保存说明、帮助卡片、底部说明和重复返回入口；登录作为默认入口，不再经过作业准备页。

账号和密码均为横向输入行：左侧标签宽 56px，右侧输入区域伸缩。两行使用细分隔线，整体左对齐，不再套表单卡片。品牌与表单间距 48px，页面左右留白 24px。密码默认隐藏并显示闭眼图标，点击后显示明文并切换为睁眼，再次点击恢复隐藏。使用 Phosphor eye / eye-closed，图标 22px，按钮 48px；透明按钮文字保留操作名称，避免原生 button 嵌套图片。保持登录放在表单下方，点击行高 48px，与主按钮间距 16px。

保留现有会话恢复、重复提交保护、提交时清空密码、登录后直接进入首页、卸载页面取消登录逻辑。错误只在输入校验或请求失败时出现；处理期间按钮保持“登录”并显示加载状态。

保持登录默认勾选：沿用 Android Keystore 加密保存刷新凭据，重开 App 后自动恢复有效会话；普通存储仅记录账号和勾选偏好，按环境、认证地址和客户端隔离。取消勾选后不保存账号和刷新凭据，当前进程仍可正常续期。显式退出继续清除安全凭据。密码不落盘，服务端会话过期或撤销后仍需重新登录。iOS / HarmonyOS 的安全登录接入仍未完成。

组件兼容依据：[DCloud image / SVG](https://doc.dcloud.net.cn/uni-app-x/component/image.html)、[checkbox](https://doc.dcloud.net.cn/uni-app-x/component/checkbox.html)。图标来源为 Phosphor Icons，许可随资源保存。

启动与恢复：首个路由复用登录页；恢复会话期间仅显示白底 Logo，结果确定后自动进入首页或展示登录表单，不添加准备页、权限确认页或人为等待。退出登录及会话失效清空页面栈后回到登录；未完成的凭据清除在登录页按需显示“重试退出”。定位与录音在对应业务操作中申请。当前 Logo 是应用内恢复状态，不是新制作的系统启动动画。
