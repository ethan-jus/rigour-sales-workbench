# 销售工作台设计基线

2026-11-11 第一版。用户选择清爽专业：白底、石墨色文字、橙色重点操作。当前先用于登录和首页，后续按业务路径逐页采用。

## 产品与使用情境

使用者是外出走访和跟进订单的销售人员。首页首先回答“本月做了多少、还有多少未收、今天要做什么”，中文信息需要在单手操作和室外阅读时保持清楚。沿用现有瑞盖标识和五个原生 Tab。

## 颜色与文字

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面底色 | #FFFFFF | 主要阅读与输入区域 |
| 石墨正文 | #252A31 | 标题、正文和关键数字 |
| 次级文字 | #626970 | 说明、日期和辅助信息 |
| 操作橙 | #C64C1C | 主按钮和可操作文字，保证白字对比度 |
| 中性底色 | #F5F6F7 | 次按钮、概览和帮助区域 |
| 浅橙底色 | #FFF2EA | 未登录引导、必要提示 |

辅助边界 #D6DBDF；错误 #B42318。颜色实现在 `app/styles/workbench-ui.css`，页面不各写一套色值。

中文使用设备系统字体，遵从 iOS、Android、HarmonyOS 的本地字体回退，不加载只覆盖拉丁字符的装饰字体。标题 28/40，区块标题 18/28，正文与主操作 16/24，辅助文字 14/22，元信息 12/20。关键文字靠字号与字重分层，不靠小字号和彩色标签堆叠。

## 构图与交互

内容左对齐，手机左右留白 24px；宽屏内容最多 560px 并居中。模块之间 28–32px，模块内部 8–20px。主按钮至少 52px，文本操作至少 48px。圆角按作用分为输入框 10px、按钮 12px、主要容器 16px；不使用统一阴影给所有内容套卡片。

首页以本人业务概览、今日数据、待办和常用入口构成层级。接口暂未接通不能成为设计中省略交易、回款和待收的理由；草稿明确保留“本机”“未提交”的含义。登录页仅保留品牌、横向账号与密码输入和“登录”按钮；错误发生时才展示提示，不增加宣传语、用途介绍、帮助卡片和底部说明。

启动自动恢复会话，已登录直接进首页，未登录进入登录页。不设置作业准备或自制权限确认页面；权限按实际操作申请。所有页面只展示当前任务所需的信息和操作，错误发生后才提示原因与恢复方式。

原生导航栏和 TabBar 负责系统安全区；内容在 scroll-view 内滚动。暂时维持现有浅色应用模式，没有新增深色主题或动画。按钮用原生 button 和 hover-class；不往原生 button 嵌套图像或容器。

## 方案取舍

首版选择“作业入口优先”，用户反馈功能过少。最新设计改为“业务概览 + 今日数据 + 行动入口 + 待办”，详见 [首页 V2 业务方案](pages/home-business-proposal.md)。V2 当前为设计原型，尚未替换 App 实现。UI UX Pro Max 检索命中了 Flat Design，采用低装饰与触控建议；它返回的营销 landing 布局、蓝绿配色和西文字体不适用，不作为项目规范。frontend-design 用于修正信息构图、中文层级与品牌橙的使用范围。

## 原生依据

- [DCloud CSS 变量](https://doc.dcloud.net.cn/uni-app-x/css/common/function.html)：VDOM 在页面根 class 定义变量，使用受支持的长写属性。
- [DCloud button](https://doc.dcloud.net.cn/uni-app-x/component/button.html)：使用文字按钮、disabled 与 hover-class，不嵌套子组件。

本基线不等于三端设备验收；本轮检查与未验证范围见 `docs/app-ui-design-20261111.md`。
